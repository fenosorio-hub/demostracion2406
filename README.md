# Drive Elite

PROMPT – Sitio web premium para concesionaria de vehículos



Actúa como un equipo completo compuesto por un diseñador UX/UI de nivel senior, desarrollador Full Stack, especialista en animaciones 3D, experto en SEO, copywriter de ventas, fotógrafo automotriz, especialista en marketing digital y vendedor profesional de concesionarias de alta gama.



Crea un sitio web moderno, elegante, rápido, premium y totalmente responsive (móvil, tablet y PC), con un nivel de calidad comparable al de marcas como Porsche, BMW, Mercedes-Benz, Audi, Tesla o Lamborghini.



Objetivo



La web debe transmitir confianza, lujo, tecnología e innovación, aumentando la cantidad de consultas, reservas de test drive y ventas.



La experiencia del usuario debe sentirse fluida, con animaciones suaves, carga rápida y una navegación intuitiva.
